## 主要な決定事項

- **WordPressは継続**する。CMSの種類はGoogleのランキング要因ではないため脱WordPressにSEO上の利得はなく、一方でAI集客エンジンの入稿経路・非エンジニアの更新運用・LLMO対策との整合という3つのコストが発生するため（根拠は [03](docs/03-research-wordpress-seo.md)）。ただし**テーマ実装にはAIコーディングを使う**
- **ページビルダー系プラグインは採用しない**（独自構文でAIエージェントが操作できないため）
- eラーニングセクションは**マイクロサイト化しない**。1ドメイン1サイトで旗艦セクション＋専用ローカルナビとする（トピッククラスタのオーソリティ集約のため）
- 業界特化3サイト（派遣・警備・建設）は、本リニューアルでは**本体にT7業界別LPを新設して相互導線を張るまで**。ドメイン統合はデータを見てPhase 4以降に判断
- サービスメニューは**3グループ構成**（経営・組織／人材開発・教育／業界向け）。**DXコンサルは撤去**
- 「お客様の声」は**静的掲載**（LMS側での自動収集はスコープ外・将来拡張）
- 動的な数値（教材数・導入社数・料金など）は**ハードコード禁止**。管理画面で一元管理し全ページへ自動反映

## 公開時の安全装置

既存URL・月間1.6〜2万セッションの資産を毀損しないため、以下を必須とする（詳細は [03](docs/03-research-wordpress-seo.md) 末尾）。

1. **段階リリース** — Google公式の「一度に1つだけ変えろ」に従い、T9コラムCTA先行 → 新設ページ群 → 既存ページ刷新の順で分割公開する
2. **URL温存を第一原則** — 既存URLは原則変更しない。リダイレクトより「変えない」ほうが安全
3. **公開前チェックリスト** — staging用noindexの解除／リダイレクトチェーンとrobots.txtブロック／canonicalの指す先／旧サイトマップの404／JSファイルのブロック／内部ナビから消えるリンクの棚卸し
4. **ロールバック基準** — どの指標がどれだけ落ちたら戻すかを公開前に数値で決めておく
5. **AI生成コードのレビュー工程** — セキュリティ・アクセシビリティ・重複コードは人間のレビューでしか止まらない
