## PART 1 グローバルナビ詳細設計

### 設計原則

1. **BOFU 3導線（料金・機能・事例）を第一階層に置く。**迷ったら「検討者が営業に聞きたいこと」順
2. **「サービス＝提供形態」「教材・研修＝学ぶ中身」に役割を分離**（現行の「サービス／研修ラインナップ」の重複を解消）。さらに**学ぶ中身の側では「eラーニング教材」「集合研修」「テーマから探す」の3切り口を並置し、どの形態の話かを常に明示する**。テーマページ（T6）は形態横断のハブとし、各テーマに対応形態バッジ（`[eラーニング]``[集合研修]`）を統一表示。「eラーニングも集合研修もできる（ハイブリッド）」はLMS専業競合に対する構造的差別化として積極的に見せる
3. グロナビはリード獲得専用。**パートナー制度・会社情報はフッターへ降格**
4. 受講者（3ヶ月960クリックのログイン流入）はヘッダー右上の専用導線で1クリック退避させ、検討者の動線と混ぜない
5. 既存URLは変更しない。新設URLは「案」であり、Phase 1の既存URL棚卸しで確定する

### T6テーマLP＝形態横断ハブ（v1.2）

各テーマLPには対応形態バッジ（🖥eラーニング／👥集合研修）を統一表示し、本文は**「eラーニングで学ぶ（該当owned講座の紹介→T8）」「集合研修で実施する（プログラム・講師→T14）」「組み合わせる（ハイブリッド活用例＋事例）」の3ブロック構成**とする。検討者は「ハラスメント研修をやりたい」というテーマ起点で来るので、形態の選択肢はテーマページの中で提示するのが自然。かつ「両方できる」はLMS専業（learningBOX等）にも研修専業にもない構造的差別化として、テーマページ・TOP・比較表で一貫して訴求する。

### 計測仕様（§08と連動）

- 全CTAクリックでGTMイベント `cta_click` を送出。パラメータ：`cta_type`（dl / demo / price / course）、`cta_position`（lead / inline / sidebar / bottombar / end / footer）、`article_category`、`cta_creative`（オファーID）
- KPIビュー：「コラム発CV」＝ランディング /column/* かつ セッション内 cv_* 発火。リニューアル前は定義上ほぼ0のため、公開初月から純増としてカウントできる
- HubSpotフォーム側は参照元記事URL・オファーIDをhiddenで受け取り、**kintoneのCV種別連携（§08）と突合可能にする**

### 初速の出し方（実装順の提案）

T9はテンプレ改修だけで全公開記事に一括適用できるため、**リニューアル本体を待たずに先行リリース可能**。効果最大の適用先はセッション上位のハラスメント系記事（m-0021ほか）×「業種別カスハラWP」で、10/1のカスハラ法施行に向けた検索急増と重なる。**9月中のT9先行公開を強く推奨**。
